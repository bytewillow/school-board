# 作业板

零 Python 第三方运行依赖：按学科看学校通知，谁都可以登记，支持多孩子。
主程序为 `app.py`；部署时需保留仓库的 `static/` 静态资源目录（含本地 PDF.js），不再仅复制单个 Python 文件。

设计约束（改界面先对这条）：只用 1 套 Bento 卡片风格、1 套柔和配色、
系统字体（不引外部字体）、不用玻璃化/黏土化/渐变/着色器；
状态必须齐全：键盘焦点态、加载中防重复提交、出错页、空状态，
动效只做 150ms 以内的过渡，且尊重复 reduced-motion。
学科展示是活页夹：大屏左侧竖排彩色标签、小屏顶部横滑标签，一次只翻一门；
封面只放最多三条紧急待办、提醒、各科计数，学科页只放紧凑标题行，计时器收进可展开，
目标是一屏看完一页，大屏活页夹内容区内部滚动、页面本身不长下拉。
边角：活页夹只有一个外框圆角 + 溢出裁剪，标签无间隙、活动标签背景就是纸面白、
圆孔只在标签与纸面之间的脊柱上；顶部不放孩子/今天过滤；
多孩先选本子封面：每本显示待办数、到期摘要和下一项，直接打开或给这个孩子登记，
不设置“不分本子看全部”入口；单孩直接进活页夹。封面用原生链接立即导航，支持键盘和新标签打开。
管理页紧凑：摘要一行、孩子/学科双栏、行内加人/加学科表单、内容每条一行，不再放登记表单；登记页也不再放新学科现填入口，新学科只走管理；本子页没有“不分本子看全部”入口。

## 本地先看效果

```bash
cd school-board
python3 app.py
# 首页 http://127.0.0.1:8765/
# 登记 http://127.0.0.1:8765/register（不需要密码）
# 管理 http://127.0.0.1:8765/admin ，原型默认密码 admin123
```

已内置 7 条示例数据：置顶提醒、语文/数学作业、英语听力、
设了可见时间的数学答案（到时间前看不到）、扫描件链接示例。

## 浏览端

- 首页保留活页夹。总览显示待完成数，分别标明逾期、今天截止、无日期；最多显示三条
  “接下来要做”，按截止日期排序（无日期排最后），其余从“全部待办”进入。共享作业也计入。
- 学科页用紧凑标题行，未完成作业排前；点标题进详情，保留搜索。各科整行均可点击。
- 桌面左侧学科标签、手机横滑标签；手机只保留底部主导航。按钮和输入框按触屏做大，
  空状态不显示误导的满进度；孩子名和切换本子入口明确。
- 图片可进入全屏查看器，翻阅当前本子、同学科的可见图片；PDF 用本地 PDF.js 逐页全屏阅读，
  支持页码跳转、缩放、键盘与滑动翻页。保留原文件打开／下载回退，不加载 CDN。
- 音频支持大号播放、进度拖动、前后 10 秒、0.75–2 倍速、整段循环和 AB 复读；
  无 JavaScript 或播放失败时可使用浏览器原生播放器。上传文件支持 HTTP Range 按段读取。
- PDF.js 为随仓库分发的客户端依赖（Apache-2.0），见 `static/pdfjs/README.md`；
  不增加 Python 包。加密、复杂字体或不兼容文件可用“原文件”交给浏览器／系统阅读器。
- 扫描全能王等外链：点“打开原链接”跳转（不在微信里打开）
- 作业打勾完成，首页显示完成数；25 分钟番茄钟

## 登记（不需要密码）

- 登记：标题、学科、类型（通知/作业/学习资料/答案/听力/提醒）、
  文字正文、原链接、截止日期、文件上传（PDF/图片/MP3，≤50MB）
- 标题不填就用文件名（去掉扩展名）；中文文件名原样保留，下载时也是原名
- 预设学科：语文、数学、英语、物理、化学、道法、历史、地理；管理里加一个新学科，就会自动出现在首页，登记页只选已有学科；活页夹只显示有内容的学科，空学科不占标签，有内容后自动出现
- 答案可见时间：填了之后，到时间前只提示“有内容未到显示时间”，看不到正文
- 置顶：提醒置顶显示

## 多孩子

- 管理页“加孩子”：多孩首页先选登记簿；每个封面包含自己的和共享的可见内容，
  不计入尚未到显示时间的内容。“给某某登记”和本子内的登记入口会沿用孩子，手动、文字、图片、语音都不必重复选人或口述姓名。
- 新登记必须属于具体孩子，不再提供共享选项。直接打开登记页时，多孩先选本子，单孩自动沿用；核对草稿时仍可逐条修正归属。
- 历史 `child_id=0` 内容不删除、不迁移，仍在每本可见，历史共享作业的完成状态继续共用。
  删除孩子仍按原有行为把其内容转为全部可见；若要重新分配历史记录，需另行决定，不能从姓名猜测归属。
- 删除孩子时，他/她专属的内容会转为全部可见，不删内容
- 还没有“每个孩子单独密码 / 单独看板”，需要的话下一版再加

## curl / iPhone 捷径上传

接口只在局域网 / Tailscale 内可信，不要对外公开。
如需加口令，部署时设 API_TOKEN，或在管理页生成令牌，请求带 `X-API-Token` 头。
配置任一种令牌后，`GET /api/items` 读取也必须带有效令牌，与写入及 `/api/lists` 一致；
未配置时保留可信局域网使用方式。这不是整个网页的登录保护，不要公开反代整个应用。

```bash
# 传一个文件，标题不填就用文件名
curl -F "file=@/path/数学练习.pdf" -F "subject=数学" -F "kind=homework" -F "child_id=1" http://HOST:8765/api/items

# 只传文字 / 链接
curl -d "title=本周通知&subject=语文&body=周五听写&child_id=1" http://HOST:8765/api/items

# 查已登记内容（JSON）
curl "http://HOST:8765/api/items?subject=数学"
```

iPhone 捷径：分享菜单 → 新建捷径 → 接收“文件/图像/PDF”→
“获取 URL 内容”选 POST、表单，地址填 `http://HOST:8765/api/items`，
先 GET `/api/lists` 获取真实孩子 id，表单里 file=捷径输入、subject=问一下（或固定一门）、child_id=所选孩子 id、kind=homework；
把捷径加到分享菜单，以后在微信里长按文件 → 分享 → 这个捷径，
一步就登记进来了。手机须和服务器在同一局域网，或都连着 Tailscale。

## 管理（需要密码）

- 删除已登记内容（文件一并删）、加孩子、加学科、删空学科
- 登记本身不需要密码，删除和管理才需要

## 这个版本刻意没做的事

- 没有微信机器人：收集先走登记上传，机器人有封主号的风险，
  以后再接也只作为往同一个登记口投稿的插件。
- 没有阅读状态、课表或复杂统计；已有作业完成状态和待办摘要。
- 没有微信 PC 文件夹监听：下一版可加一个 watcher，把微信下载目录的新文件
  推到登记口。

PWA：图标是蓝底白纸活页夹（彩色标签 + 完成对勾），manifest 名“作业登记簿”/简称“登记簿”，
独立打开；iPhone 用 Safari 分享 → 添加到主屏幕即可，作业数据不离线缓存，断网只提示。

Docker 镜像（GitHub Actions 自动构建）：
```bash
docker pull ghcr.io/bytewillow/school-board:latest
docker run -d --name school-board -p 8765:8765 \
  -e ADMIN_PASSWORD='你自己设的密码' -v ./data:/data \
  ghcr.io/bytewillow/school-board:latest
```
本地用 compose 部署时，先在 shell 里 `export ADMIN_PASSWORD='你自己设的密码'`，再 `docker compose up -d --build`；默认只绑 127.0.0.1，局域网访问再把端口改成 `8765:8765`，不要直接公网暴露。

## AI 录入

- 方案一（登记页集成）：手动登记与“文字 / 拍照 / 语音”并列，默认手动。写一句话或拍一张作业单，
  AI 先拆成草稿，你逐条核对后再批量创建，草稿确认前不入库；没配 LLM 时用
  下面的粘贴 JSON（免费聊天 App 里解析完复制过来也行）。部分创建失败时，只移除成功项，
  失败及未勾选草稿保留；连接中断时结果可能已写入，请先检查本子，勿盲目重复提交。
  使用已配置模型会把文字/照片发送给服务商，可能产生 API 费用。LLM 配置见 app.py
  头部环境变量：`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`、`LLM_VISION_MODEL`。
- 方案二（外部 AI 调 API）：管理页“API 令牌（给 AI 用）”生成令牌，只存哈希，
  生成那一刻外不显示明文；AI 的完整用法见仓库根目录 `SKILL.md`，要点是先
  `GET /api/lists` 再逐条 `POST /api/items`，确认后才创建，令牌允许查列表、读取可见内容和
  创建，不能删除和管理。公开域名走 Caddy 时只反代 `/api/lists` 和 `/api/items`，
  不要反代 `/admin`、`/api/ai-parse`、`/api/ai-voice`、`/api/ai-batch`。

### 语音录入：提交即解析，确认后才创建

- 在孩子的登记页切到“文字 / 拍照 / 语音”，点“开始录音”，说完点“提交语音并解析”。
  服务端先转写再解析，直接显示现有可编辑草稿，不必再点识别；不会自动创建作业。
  也可选择已有录音文件，选择后直接解析。原有文字 / 照片、手动登记和粘贴 JSON 路径不变。
- 浏览器录音需要 HTTPS 安全上下文（本机 `localhost` 例外）、麦克风权限及 MediaRecorder 支持。
  普通局域网 HTTP 地址通常不能录音，仍可选择录音文件或用文字 / 照片。手机/平板的授权和编码格式因浏览器而异。
- 录音上限 2 分钟，达到后停止但**不自动提交**；可提交或取消。音频上限 10MB。
  支持 WebM、MP4/M4A、WAV、MP3、Ogg，请确认服务商也支持所用格式。取消录音不发送音频。
- 在服务端配置 `STT_API_KEY`、`STT_BASE_URL`（默认 `https://api.openai.com/v1`）、
  `STT_MODEL`（默认 `whisper-1`）；接口须支持 OpenAI 兼容 multipart `POST /audio/transcriptions`
  和 `response_format=json`，返回 `{"text":"转写文字"}`。同时保留原有 `LLM_*` 配置。
  默认聊天服务 DeepSeek 不代表提供转写，语音密钥与聊天密钥独立；没配置时语音入口明确禁用。
  Compose 可从 shell / `.env` 传入上述变量，修改后重新创建容器；密钥只在服务端，不要提交到仓库。
- 提交会把音频经服务器发送给所配置的语音服务，转写文字再发给所配置的聊天模型，可能分别计费。
  原始音频不写入本地文件或作业附件，转写文字回填页面供修改；服务商的保留政策以其条款为准。
  转写成功而 AI 解析失败会保留文字，可修改后仅重试文字解析；超时可能已被服务商处理或计费，不要连续盲目重试。
- `/api/ai-voice` 与文字 AI 接口一样，仅供可信家庭网络中的登记页使用；它不是有独立登录保护的公开服务。
  不要直接反代到公网。新增作业的 HTTP 接口均要求有效具体孩子 id；旧捷径若缺少 `child_id` 或传 `0`，需更新。
