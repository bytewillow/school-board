# 作业板

零依赖 Python 单文件：按学科看学校通知，谁都可以登记，支持多孩子。

设计约束（改界面先对这条）：只用 1 套 Bento 卡片风格、1 套柔和配色、
系统字体（不引外部字体）、不用玻璃化/黏土化/渐变/着色器；
状态必须齐全：键盘焦点态、加载中防重复提交、出错页、空状态，
动效只做 150ms 以内的过渡，且尊重复 reduced-motion。
学科展示是活页夹：大屏左侧竖排彩色标签、小屏顶部横滑标签，一次只翻一门；
封面只放进度、提醒、各科计数，学科页只放紧凑标题行，计时器收进可展开，
目标是一屏看完一页，大屏活页夹内容区内部滚动、页面本身不长下拉。
边角：活页夹只有一个外框圆角 + 溢出裁剪，标签无间隙、活动标签背景就是纸面白、
圆孔只在标签与纸面之间的脊柱上；顶部不再放孩子/今天过滤，默认看全部；
多孩先选本子封面（封面写“xx的作业登记簿”，不写提示语、不写大标题、
不放“换本子”，顶部只留一行小导航）、点开带翻书动画（650ms，单孩直接进活页夹，不走本子页）。
管理页紧凑：摘要一行、孩子/学科双栏、行内加人/加学科表单、内容每条一行，不再放登记表单；登记页也不再放新学科现填入口，新学科只走管理；本子页没有“不分本子看全部”入口。

## 本地先看效果

```bash
cd school-board
python3 app.py
# 首页 http://127.0.0.1:8765/
# 登记 http://127.0.0.1:8765/register（不需要密码）
# 管理 http://127.0.0.1:8765/admin ，原型默认密码 admin123
```

已内置 7 条示例数据：置顶提醒、语文/数学作业、英语听力、
设了可见时间的数学答案（到时间前看不到）、扫描件链接示例。

## 浏览端

- 首页一个学科一个卡片块（不是一条长列表）：每块带学科图标和柔和底色，
  只列最多 3 条标题，点“进入学科”才看这门全部；学科页同样只列标题行，
  点标题进详情才展开正文、PDF、图片、音频
- 今天 / 全部切换、搜索、今日进度条（不做红色催促）；按钮和输入框都按
  触屏尺寸做大（≥48px）；大屏多列铺满，小屏单列 + 底部导航（首页/登记/管理）
- PDF 内嵌浏览、图片直显、MP3 播放（变速 0.75/1/1.25、循环）
- 扫描全能王等外链：点“打开原链接”跳转（不在微信里打开）
- 作业打勾完成，首页显示完成数；25 分钟番茄钟

## 登记（不需要密码）

- 登记：标题、学科、类型（通知/作业/学习资料/答案/听力/提醒）、
  文字正文、原链接、截止日期、文件上传（PDF/图片/MP3，≤50MB）
- 标题不填就用文件名（去掉扩展名）；中文文件名原样保留，下载时也是原名
- 预设学科：语文、数学、英语、物理、化学、道法、历史、地理；管理里加一个新学科，就会自动出现在首页，登记页只选已有学科；活页夹只显示有内容的学科，空学科不占标签，有内容后自动出现
- 答案可见时间：填了之后，到时间前只提示“有内容未到显示时间”，看不到正文
- 置顶：提醒置顶显示

## 多孩子

- 管理页“加孩子”：登记时选“给谁”，首页顶部点孩子名就只看他/她的；
  不选孩子的内容对所有孩子可见（同班、同一份通知用“全部”就行，不用登两遍）
- 删除孩子时，他/她专属的内容会转为全部可见，不删内容
- 还没有“每个孩子单独密码 / 单独看板”，需要的话下一版再加

## curl / iPhone 捷径上传

接口只在局域网 / Tailscale 内可信，不要对外公开。
如需加口令，部署时设 API_TOKEN，请求带 `X-API-Token` 头。

```bash
# 传一个文件，标题不填就用文件名
curl -F "file=@/path/数学练习.pdf" -F "subject=数学" -F "kind=homework" http://HOST:8765/api/items

# 只传文字 / 链接
curl -d "title=本周通知&subject=语文&body=周五听写" http://HOST:8765/api/items

# 查已登记内容（JSON）
curl "http://HOST:8765/api/items?subject=数学"
```

iPhone 捷径：分享菜单 → 新建捷径 → 接收“文件/图像/PDF”→
“获取 URL 内容”选 POST、表单，地址填 `http://HOST:8765/api/items`，
表单里 file=捷径输入、subject=问一下（或固定一门）、kind=homework；
把捷径加到分享菜单，以后在微信里长按文件 → 分享 → 这个捷径，
一步就登记进来了。手机须和服务器在同一局域网，或都连着 Tailscale。

## 管理（需要密码）

- 删除已登记内容（文件一并删）、加孩子、加学科、删空学科
- 登记本身不需要密码，删除和管理才需要

## 部署到家里 Docker（示例）

```bash
# 改 docker-compose.yml 里的 ADMIN_PASSWORD，再：
docker compose up -d --build
# 局域网 / Tailscale 访问 8765 端口即可；不要直接公网暴露。
# 备份：把 ./data 整个拷走（含 SQLite 库和上传文件）。
```

## 这个版本刻意没做的事

- 没有微信机器人：收集先走登记上传，机器人有封主号的风险，
  以后再接也只作为往同一个登记口投稿的插件。
- 没有阅读状态、课表、完成统计：下一版再加。
- 没有微信 PC 文件夹监听：下一版可加一个 watcher，把微信下载目录的新文件
  推到登记口。

PWA：图标是蓝底白纸活页夹（彩色标签 + 完成对勾），manifest 名“作业登记簿”/简称“登记簿”，
独立打开；iPhone 用 Safari 分享 → 添加到主屏幕即可，作业数据不离线缓存，断网只提示。

Docker 镜像（GitHub Actions 自动构建）：
```bash
docker pull ghcr.io/bytewillow/school-board:latest
docker run -d --name school-board -p 8765:8765 \
  -e ADMIN_PASSWORD='你自己设的密码' -v ./data:/data \
  ghcr.io/bytewillow/school-board:latest
```
本地用 compose 部署时，先在 shell 里 `export ADMIN_PASSWORD='你自己设的密码'`，再 `docker compose up -d --build`；默认只绑 127.0.0.1，局域网访问再把端口改成 `8765:8765`，不要直接公网暴露。
