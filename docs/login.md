# 家长 / 学生登录与 HTTPS 部署说明（2.0）

2.0 沿用 1.x 的会话表、cookie 名和密码哈希格式，升级后已登录的设备不用重新登录。

## 登录与会话

- 打开任意页面，没登录会进到 `/login`。页面上有“我是学生 / 我是家长”两个标签：学生填名字和密码，家长填 `ADMIN_PASSWORD`。旧链接 `/admin` 没登录时会打开家长登录。
- 家长在“管理”里给每个孩子设至少 6 位的密码，只显示“已设密码 / 未设密码”，不回显。改密码、清密码、删除孩子都会让这个孩子所有已登录的设备退出。改名保留密码。
- 所有失败统一提示“名字或密码不对”；名字不存在时也做一次同样耗时的计算，不能从响应时间猜出孩子名单。
- 密码：每次随机 16 字节 salt + PBKDF2-HMAC-SHA256（200000 次），存 `salt_hex:hash_hex`。会话 token 只在 HttpOnly cookie 里，数据库只存 SHA256，有效期 30 天。
- Cookie：`sb_session=…; Path=/; HttpOnly; SameSite=Lax; Max-Age=2592000`，请求带 `X-Forwarded-Proto: https` 时加 `Secure`。代理必须覆盖这个头，不能让客户端自己注入。旧版的 `admin` cookie 继续当家长识别（它没有服务端会话，退出登录撤销不了复制出去的旧 cookie）。
- 退出登录会删掉会话、清掉新旧 cookie，并清空这台设备上缓存的作业数据。

## 权限

| 接口 | 未登录 | 家长 | 学生 |
| --- | --- | --- | --- |
| 页面（`/`、`/calendar`、`/item/…` 等） | 返回页面，前端跳到登录 | 全部本子，先选本子 | 只有自己 |
| `/app-api/items*` | 401 | 任意孩子，能看到“定时显示”中的内容 | 自己 + 共享；未公开的 404；别人的 404 |
| 修改 / 删除作业 | 401 | 全部，可换本子 | 只能改自己本子里、已公开的；共享内容不能改删 |
| 完成 / 步骤打勾 | 401 | 全部 | 自己 + 共享（共享的完成状态所有本子同步，与 1.x 一样） |
| `/app-api/admin/*` | 401 | 可以 | 403 |
| `/uploads/*` | 303 到 `/login` | 全部 | 自己 + 共享且已公开的，否则 404 |
| 三个 `/api/ai-*` | 401 | 可以 | parse / voice 给别人解析 400；batch 里别人的草稿逐条失败 |
| `/api/lists`、`/api/items` | 令牌规则（见下） | 不因会话绕过令牌 | 同左 |
| `/api`、`/health`、静态文件、图标、`/manifest.json`、`/sw.js` | 公开 | 公开 | 公开 |

`/api/lists`、`/api/items` 的令牌规则与 1.x 相同：配置了环境变量令牌或管理页生成过令牌，就必须带有效令牌，否则 401；一个令牌都没有时保留局域网匿名读写。**公网访问前一定先配置令牌。**

同源保护：带了跨站 `Origin` 的写请求一律 403（`/api/items` 除外，保留命令行用法）。学生上传的 HTML / SVG / XML 只能下载，并加 `Content-Security-Policy: sandbox` 和 `nosniff`。

## HTTPS 反向代理（Caddy 示例，模板）

装到手机主屏幕、接收推送都要求 HTTPS。整站反代：

```
homework.example.com {
  request_body {
    max_size 60MB
  }
  reverse_proxy 127.0.0.1:8765 {
    header_up X-Forwarded-Proto {scheme}
  }
}
```

只想让外部 AI 访问、不开放网页时，仍然可以只反代 `/api/lists` 和 `/api/items`，见 [SKILL.md](../SKILL.md) 第 5 节。

## 上线后核对

1. 无痕窗口打开首页应进到登录页；带 / 不带令牌分别请求两个令牌接口。
2. 家长登录、管理、给孩子设密码；学生登录只看到自己；打开别人的作业链接是“没找到”；改密码后旧设备被退出。
3. 经 HTTPS 时 `Set-Cookie` 带 `Secure`。
4. iPhone：Safari 添加到主屏幕 → 从图标打开 → “我的”里打开提醒 → “试一条截止提醒”能收到；开始专注后锁屏，到点能收到“专注时间到”。
